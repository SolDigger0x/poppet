# POPPET — Stitched for Chaos

Interactive Solana meme-token landing page.

## Live
https://poppet-hex.netlify.app

## Structure
- `index.html` — page structure + embedded bear art
- `styles.css` — all styles
- `app.js` — ritual, wallet, social, token actions
- `netlify.toml` — headers & SPA fallback

## Features
- Pin-the-bear Hex ritual (13 pins)
- Solana wallet connect (Phantom / Solflare) + SOL balance
- Jupiter buy deep-link once CA is set
- Hex Badge claim (wallet-signed message)
- Social sharing, referrals, tweet curses
- Cosmetic skins, curse book, leaderboard
